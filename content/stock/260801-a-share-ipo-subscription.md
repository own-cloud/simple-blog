# A股打新（新股申购）规则与策略

- Created at: 2026/08/01

## Context
- 用户对A股打新感兴趣，想了解规则、条件和近期机会
- 目前只关注沪深主板，开户不满2年，暂无创业板/科创板/北交所权限

## Key Concepts
- **打新**：以发行价申购即将上市的IPO新股，上市后卖出赚差价
- **市值门槛**：申购前20个交易日，日均持有非限售A股市值 ≥ 1万元
- **沪深分开计算**：沪市市值只能打沪市新股，深市市值只能打深市新股
- **额度换算**：沪市每1万元 = 1000股；深市每5000元 = 500股
- **中签机制**：市值配售 + 摇号，中签率极低（2025年平均约0.04%）
- **缴款规则**：沪深市场申购时不冻结资金，中签后T+2日16:00前缴款

## 各板块差异

| 板块 | 市值门槛 | 资金要求 | 权限开通条件 |
|------|---------|---------|------------|
| 沪深主板 | ≥1万 | 中签后缴款 | 普通A股账户即可 |
| 创业板 | ≥1万 | 中签后缴款 | 日均资产≥10万 + 2年交易经验 |
| 科创板 | ≥1万 | 中签后缴款 | 日均资产≥50万 + 2年交易经验 |
| 北交所 | 无市值要求 | 申购时全额冻结 | 日均资产≥50万 + 2年交易经验 |

## 申购流程
```
T日（申购日）  →  9:30-15:00 提交申购，顶格打
T+1日         →  公布中签率，摇号配号
T+2日         →  公布中签结果，16:00前缴款（沪深）
上市首日       →  卖出（或继续持有）
```

## 提高中签率策略
- **顶格申购**：有多少额度打多少
- **沪深各配1万+**：两边都能参与
- **家庭多账户**：用家人身份证开户独立申购（同一人多账户无效）
- **申购时间**：数据显示14:30-15:00中签概率比早盘高峰略高（约1.7倍）
- **坚持打**：概率低但长期坚持

## 风险
- **破发风险**：注册制下新股破发率约15%-18%，不是稳赚
- **弃购惩罚**：12个月内累计3次中签未缴款，6个月禁止打新
- **中签率极低**：平均约万分之四
