# A股上市公司财报披露时间规则

- Created at: 2026/08/01

## Context
- 用户在学习A股投资基础知识，需要了解上市公司财报的披露节奏和时间节点
- 用于判断何时关注哪些财报、识别业绩好坏的信号

## 四份财报及截止日

| 报告 | 覆盖期间 | 披露截止日 | 审计要求 |
|------|---------|-----------|---------|
| 年报 | 1-12月（全年） | 次年4月30日 | 必须审计 |
| 一季报 | 1-3月 | 4月30日 | 不审计 |
| 半年报（中报） | 1-6月 | 8月31日 | 通常不审计 |
| 三季报 | 1-9月 | 10月31日 | 不审计 |

## 三种披露形式（按时间先后）

```
业绩预告 → 业绩快报 → 正式报告
（最早）    （较详细）   （最终版，年报经审计）
```

- **业绩预告**：提前剧透净利润大概情况，可能有误差
- **业绩快报**：主要财务数据，比预告准确，但仍可能变脸
- **正式报告**：完整财报，最权威

## 实际披露节奏

### 年报 + 一季报（1月-4月）
- 1月中旬开始有公司陆续披露年报
- 4月是披露高峰
- "好学生"先交卷：业绩好的公司倾向早披露
- ST公司、业绩差的公司往往拖到最后几天
- 一季报披露时间**不得早于该公司年报披露时间**
- 4月30日是硬性截止日，未按期披露将被证监会立案调查

### 半年报（7月-8月）
- 7月15日前：业绩预告截止（净利润变动超50%等情形须强制预告）
- 8月是中报密集披露期
- 同样好公司先披露

### 三季报（10月）
- 10月31日前披露完毕
- 内容最简，主要披露核心财务数据

## 业绩预告规则

- **年报/中报**：特定情形下强制预告（净利润为负、扭亏为盈、同比变动超50%）
- **一季报/三季报**：自愿披露，无强制要求

## 投资者关注时间点

| 时间 | 关注内容 |
|------|---------|
| 1月中旬 | 年报预告开始 |
| 3-4月 | 年报+一季报密集披露期 |
| 7月15日前 | 中报业绩预告截止 |
| 7-8月 | 中报披露季 |
| 10月 | 三季报披露季 |

## 实用规律
- 业绩好的公司抢着先披露，拖到最后的往往是"差生"
- 公司迟迟不披露，市场通常视为负面信号
- 延期披露的公司需重点关注，尤其是ST公司
- 已披露公司的整体增速不宜简单外推（先披露的多为好学生）
