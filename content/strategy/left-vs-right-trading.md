# 左侧交易 vs 右侧交易

## 核心区别

以抄底/逃顶为例：

```
价格
  ↑
  |         ╱╲
  |       ╱    ╲
  |     ╱   ●    ╲   ← 右侧交易：等趋势确认再进出
  |   ╱            ╲
  └────────────────→ 时间
  ⏺                  ← 左侧交易：在下跌中提前买入
```

---

## 左侧交易（逆势）

**定义：** 在价格还在跌的时候买入，在还没涨的时候就卖出。

**特点：**
- 追求买在最低点、卖在最高点附近
- 需要极强的判断力和耐心
- 风险大，但潜在收益也最大
- 典型心理："别人恐惧时我贪婪"

**适合人群：** 有丰富经验、能扛波动、基本面分析强的投资者

---

## 右侧交易（顺势）

**定义：** 等趋势明确转向后再行动，不猜底、不猜顶。

**特点：**
- 安全系数高，错过一部分底部利润
- 适合大多数普通投资者
- 核心思想：让市场告诉你趋势

---

## 对比总结

| | 左侧交易 | 右侧交易 |
|---|---------|---------|
| **方向** | 逆势 | 顺势 |
| **买卖时机** | 提前 | 确认后 |
| **风险** | 高（可能买在半山腰） | 较低 |
| **潜在收益** | 更大 | 较小 |
| **对能力要求** | 高 | 低 |
| **心理压力** | 大 | 小 |

---

## 实战案例

某股票从 100 元跌到 50 元：

```
左侧交易者：
  90元 → 开始建仓
  70元 → 加仓
  50元 → 全仓（最痛的时候在买）
  60元 → 减仓
  结果：可能抄在半山腰

右侧交易者：
  50元 → 观望（不确定是否到底）
  55元 → 站上MA20，观察
  60元 → 突破下降趋势线 + 成交量放大 → 买入
  结果：少赚一部分，但确定性高得多
```

---

## 右侧交易实战步骤

### 抄底流程

```
1. 观察 → 价格连续下跌，出现止跌迹象（小阳线、长下影线），但不操作
2. 等信号 → 价格突破下降趋势线 / 站上 MA20 / MA5 上穿 MA20
3. 确认 → 连续3天收盘在 MA20 上方 + 成交量放大
4. 买入 → 分批建仓（30% → 确认上涨再加30% → 最后40%）
5. 止损 → 设明确止损位（如跌破 MA20 2% 止损）
```

### 逃顶流程

```
1. 观察 → 价格连续上涨，出现滞涨迹象（长上影线、高位十字星），不卖
2. 等信号 → 价格跌破上升趋势线 / 跌破 MA20 / MA5 下穿 MA20
3. 确认 → 连续3天收盘在 MA20 下方
4. 卖出 → 分批卖出（30% → 确认下跌再清70%）
```

## 常用判断指标

### 均线系统（最简单有效）

```
MA5 / MA10 / MA20 / MA60

买入信号：
  ✅ 价格突破 MA20 并站稳
  ✅ MA5 上穿 MA20（金叉）
  ✅ 均线开始向上发散

卖出信号：
  ✅ 价格跌破 MA20
  ✅ MA5 下穿 MA20（死叉）
  ✅ 均线开始向下发散
```

### 成交量配合

```
底部放量上涨 → 资金进场，可信度高
下跌缩量 → 抛压减轻，可能接近底部
但缩量不一定是底部，要等放量确认
```

---

## 常见陷阱

| 陷阱 | 说明 | 避免方法 |
|------|------|---------|
| **假突破** | 突破后立刻跌回 | 等3天确认，或用成交量验证 |
| **买在半山腰** | 趋势未确认就买入 | 严格等信号，不提前行动 |
| **卖飞** | 卖早了后面继续涨 | 分批卖出，留一部分观察 |
| **止损不设** | 以为右侧就不会亏 | 右侧也有假信号，必须止损 |
| **等太久** | 错过最佳买点 | 设定明确规则，规则到了就执行 |

---

## 总结

> **右侧交易 = 等信号 → 确认 → 跟随 → 设好止损**

- 宁可错过，不可做错
- 利润可能只有 30%-50% 的波段，但胜率高
- 趋势是你的朋友，顺势而为
- 不要因为"觉得到底了"就提前行动

---

**一句话总结：** 左侧交易是"猜底买"，右侧交易是"趋势确认后买"。大多数普通投资者适合右侧交易。
